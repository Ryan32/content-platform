Viewer stack

One viewer for every format, built from proven open-source libraries

It builds on what the platform already has: PDF.js, the protected file route and Vimeo IDs. Office files are converted to PDF in the processing worker, so restricted content never leaves AWS.

How it works

  • One viewer component (AssetViewer) picks the right viewer from the file type. Every format gets the same page header, side panel, Ask AXL, Save and Copy link.
  • View and download are separate permissions. Viewing uses a generated copy (rendered pages, transcript or thumbnail). Download serves the original only when it’s allowed.
  • Every viewer can open at an exact spot: a page, a slide, a cell or a timestamp. AXL citations and shared links rely on this.
  • Readers who can view but not download see a light watermark with their name and the date on documents.
  • The processing worker creates thumbnails, converted PDFs, transcripts and chapters as part of the AI pipeline. Readers never wait for a conversion.
